## 🎨 Design & Technical Architecture

- **Zero Heavy Frameworks**: Pure static semantic HTML5, modern CSS3, and vanilla ES6+ JavaScript. Fast, secure, zero build step, and instantly hosted on GitHub Pages.
- **Obsidian Luxury Design**: Deep dark space foundation (`#06070a`, `#08090d`), ambient glowing radial mesh, and micro-grid texture.
- **Interactive Mouse Glow**: Dynamic CSS variable tracking (`--mouse-x`, `--mouse-y`) on `.glow-card` elements for high-end tactile feedback.
- **Editorial Typography**: Pairing Google Fonts **Plus Jakarta Sans** (display), **Inter** (body), and **JetBrains Mono** (technical badges, telemetry, metrics).
- **Responsive & Accessible**: Mobile-first architecture, WCAG AA contrast compliance, keyboard focus rings (`:focus-visible`), and `prefers-reduced-motion` adaptability.
- **Schema.org Structured Data**: Integrated JSON-LD for `Organization`, `Person`, and `SoftwareApplication`.

## 🛠 Local Development & Testing

Since this project requires no build tools, you can serve it with any local HTTP server:

```bash
# Python 3
python -m http.server 8080

# Node.js
npx serve .

# PHP
php -S localhost:8080
```

Open `http://localhost:8080` in your browser.
